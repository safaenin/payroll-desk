## Cloud lifecycle integration

`npm run test:rules` now also runs `tests/cloud.integration.test.ts` against a separate demo emulator project. The test uses the production `loadCloud`, `saveCloud`, `approve`, `addPayment`, and advance functions with 35 fictional employees and 1,050 attendance entries. It verifies reloading issued advances, approved pay, a payment, two revisions with exact original snapshots, unchanged payment records, recovery counted once, and stale-session rejection. All eight rule tests and this integration test passed. The ordinary suite passed 120 tests (the integration test intentionally skips without the emulator); production build passed. No production writes were made.
